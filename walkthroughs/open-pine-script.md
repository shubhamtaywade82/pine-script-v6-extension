# Open a Pine Script file

1. In the Extension Development Host window, use **File → Open File** and pick a `.pine` file (for example `examples/demo.pine` in this repo).

2. Confirm the status bar language mode is **Pine Script** (or **Pine Script v6**). If it shows **Plain Text**, click it and select **Pine Script**, or rely on `files.associations` for `*.pine`.

3. You should see **PineForge** diagnostics, hovers on known APIs, and commands such as **Pine Script: Open v6 Reference Manual** in the Command Palette.

TradingView remains the authoritative compiler for full syntax and runtime behavior.
